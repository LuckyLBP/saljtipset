Första gången du öppnar appen

Mac

  1. Öppna den nedladdade .dmg-filen och dra Bubbe till Program.
  2. Högerklicka på Bubbe i Program och välj Öppna, och sedan Öppna igen.
  3. Säger macOS att appen inte kan öppnas? Gå till Systeminställningar → Integritet och säkerhet och klicka Öppna ändå.

Windows

  1. Kör den nedladdade installationsfilen.
  2. Visas "Windows skyddade datorn"? Klicka Mer information och sedan Kör ändå.
  3. Bubbe använder grafikkortet om det finns, annars processorn.
